# 维护脚本

脚本统一放在本目录。当前已实现：

- `sync-photos.mjs`：扫描原片、读取 EXIF/GPS、生成去元数据网页副本，并更新按首次同步时间排序的照片清单。

照片正式发布不通过同步脚本完成，而是在 `/studio` 浏览器端读取 EXIF、生成网页版本，再把原片与网页版本分别写入 R2、元数据写入 D1。同步脚本只负责仓库内本地照片的离线回退清单。

后续预期包括：

- 原图隐私元数据检查。
- 响应式图片生成。
- 素材许可登记完整性检查。
- 内容 frontmatter 校验。
- 失效链接扫描。
- R2 对象清单与备份验证。

脚本必须可重复运行，不覆盖原始照片，并在失败时返回非零状态。
