## 1. 暗房照片展示升级

### 1.1 胶卷展开与相纸晾晒模式

- [x] 影集首次进入时，播放一次短的胶卷展开动画。
- [x] 默认照片展示改为暗房晾晒：照片以晾晒绳、上方挂钩夹和下方配重夹的真实胶片夹结构转译呈现，不再使用遮挡画面的胶带。
- [x] 照片错落排列，保留横竖照片比例和清晰的标题、地点、年份信息。
- [x] 滚动进入时照片分批落下或显影，动画结束后不循环播放。
- [x] 点击单张照片进入现有灯箱，可关闭、前后切换，并支持键盘方向键。
- [x] 移除难以控制的自由拖拽光桌，替换为单张审片模式：大图、胶片索引、进度、前后切换、键盘与横向滑动。
- [x] 鼠标悬停或键盘聚焦晾晒照片时，照片主体围绕夹点做一次轻微阻尼摆动；减少动态偏好下保持静止。

设计边界：不使用胶带固定照片，也不把小夹子画成照片中央的装饰方块；参考真实暗房胶片夹的“晾晒绳 + 弹簧夹 + 下方配重”关系，再转译成照片晾晒装置。胶卷动画只承担“进入暗房”的叙事，不阻塞后续浏览。

### 1.2 暗房背景物件

- [x] 增加低对比度的暗房放大机、晾晒线、红色安全灯和胶卷轮廓。
- [x] 默认背景物件不抢夺照片和文字的焦点，装饰层使用低透明度和 `pointer-events: none`。
- [x] 先实现安全灯作为第一个有内容关系的互动热点。
- [x] 点击安全灯可以切换暗房环境光。
- [x] 移动端简化背景物件，避免遮挡照片和增加滚动负担。

设计边界：不加入漂浮粒子、鼠标拖尾、连续旋转胶卷、伪终端或游戏化地图。

### 1.3 相纸反光与曝光反馈

- [x] 鼠标悬停或触屏聚焦时，照片出现一次轻微的相纸反光。
- [x] 首次进入暗房时播放一次短促的暖白曝光过渡。
- [x] 不使用循环闪烁或全屏强白光。
- [x] 遵守 `prefers-reduced-motion: reduce`：关闭连续动画和曝光闪光，但保留照片查看和所有信息。
- [x] 触屏、键盘和辅助技术不依赖 hover 才能完成操作。

安全边界：不制作连续高对比度闪烁；所有闪光必须短、弱、可跳过，并且不能遮住核心内容。

### 1.4 最新照片与 EXIF

- [x] 原片同步后按首次上传时间排序，影集顶部固定显示最新三张。
- [x] 自动读取原片 EXIF，并默认展示相机、镜头、焦距、光圈、快门、ISO、拍摄时间和地点。
- [x] 公开网页图片继续移除 EXIF/GPS，只将经过选择的文字元数据写入内容清单。
- [x] 支持通过照片覆盖配置修改标题、主题、地点，并使用 `hideGps` 隐藏精确坐标。

## 6. V2 照片发布链路

### 已实现

- `/studio` 仅允许站点 owner 进入；本地开发可以使用受限的 `x-local-studio-owner` 测试头，生产环境仍要求托管平台注入的 ChatGPT 身份头。
- 浏览器读取原片 EXIF，并生成最长边 2400px 的去元数据 JPEG；R2 分开保存原片和网页版本。
- D1 保存标题、替代文字、影集标识、主题、拍摄时间、相机参数、GPS 展示级别、状态和排序字段。
- 状态流转为 `draft → published → archived`；没有网页版本时禁止发布。
- 原片不通过公开媒体路由提供；公开路由只读取已发布网页版本。
- 已发布 D1 照片与仓库内本地照片合并，上传照片按发布时间进入首页最新三张。
