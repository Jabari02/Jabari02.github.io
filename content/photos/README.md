# 照片内容清单

- `photo-overrides.json`：人工维护标题、替代文本、地点、主题、网页文件名和隐私覆盖项。
- `photos.generated.json`：由 `npm run photos:sync` 自动生成，页面直接读取，不应手工修改。

正式上传的照片通过 `/studio` 写入 D1 + R2，不会修改这个本地生成清单。公开目录会将已发布云端照片与这里的本地照片合并；因此第一次配置云端或云端暂时不可用时，网站仍能正常预览。

发布工作流与绑定、迁移、隐私边界见 `docs/02-photo-publishing.md`。

排序首先使用 `uploadedAt`，同一次同步内再按 EXIF 拍摄时间排序。新原片第一次出现时会写入当前同步时间，后续重复执行不会改变其上传顺序。

默认展示相机、镜头、焦距、光圈、快门、ISO、拍摄时间与 EXIF GPS。公开前如不希望展示精确坐标，请在对应照片覆盖项中设置 `"hideGps": true`，然后重新同步。
